תוכנית העריכות
==============

E1 — router.py: presence stamp ב-get_current_user בלבד
------------------------------------------------------

מיד לפני return user, אחרי שכל בדיקות הסטטוס עברו:

    # Presence stamp (best-effort, throttled): real "last seen" for
    # team-activity / admin recency. Never blocks or fails auth.
    try:
        _seen_raw = user.get('last_seen_at')
        _stale = True
        if _seen_raw:
            _seen_dt = datetime.fromisoformat(str(_seen_raw).replace('Z', '+00:00'))
            _stale = (datetime.now(timezone.utc) - _seen_dt) > timedelta(minutes=10)
        if _stale:
            _now_iso = datetime.now(timezone.utc).isoformat()
            await db.users.update_one(
                {'id': user['id']},
                {'$set': {'last_seen_at': _now_iso}},
            )
            user['last_seen_at'] = _now_iso
    except Exception:
        pass

מאפיינים מחייבים:
- לכל היותר write אחד למשתמש בכל 10 דקות.
- best-effort; כל exception נבלע.
- auth result נשאר זהה.
- משתמשים pending/suspended/pending_deletion לא מגיעים ל-stamp.
- לא נוגעים ב-get_current_user_allow_pending_deletion.


E2 — stats_router.py: later-of לשימוש ב-team activity
-----------------------------------------------------

1. להוסיף last_seen_at ל-projection.
2. להחליף רק את חישוב login_days_ago:

    _candidates = []
    for _k in ('last_seen_at', 'last_login_at'):
        _v = u.get(_k)
        if _v:
            try:
                _candidates.append(
                    datetime.fromisoformat(str(_v).replace('Z', '+00:00'))
                )
            except Exception:
                pass
    login_days_ago = (
        max(0, (now - max(_candidates)).days)
        if _candidates else None
    )

כל מה שממשיך אחרי החישוב נשאר ללא שינוי:
