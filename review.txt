IMPLEMENTATION
===============================================================================

Backend:
- Added pure escalation helpers for the spare-status snapshot, Hebrew context
  line, default message, eligibility, and notification bodies.
- Added the field-escalation router:
  - POST creates an escalation or appends a note to the existing open one.
  - GET lists open/resolved/all items with role visibility and counts.
  - PATCH handles done, dismiss, note, assign, and unassign.
- Stored context is structured data, not only text.
- PM/owner can see all project escalations.
- management_team can see only items requested by or assigned to them.
- contractor/viewer cannot list or create escalations.
- Unit detail returns additive `spare_can_escalate` and
  `spare_escalation` keys without changing existing keys.
- Added in-app notification types, links, action mapping, and additive `extra`
  fields while preserving existing QC notification behavior.
- Added project/status/date and unit/status indexes.
- The `(unit_id, status)` index is a unique partial index only for
  `{type: "spare_tiles", status: "open"}`.
- Startup establishes and verifies that correctness-critical unique index
  before accepting traffic and fails closed if it cannot do so.
- Concurrent duplicate creates retry as a note on the winning open escalation.
- Concurrent done/dismiss updates are conditional on status=open, so only one
  request audits and notifies.

Frontend:
- Added `escalationService` for create/list/patch.
- Added Hebrew relative-time, sub-role-label, and escalation-draft utilities.
- Added an accessible escalation sheet with title and description, structured
  automatic context, urgency, editable text, character count, submit feedback,
  and the explicit in-app/no-WhatsApp message.
- Added unit-card escalation status and note/new-escalation actions.
- Added dashboard focus rows and the
  `הקפצות מהשטח · לטיפולי` fold with done, dismiss, assign, open-unit,
  note display, and resolved-week display.
- Added deep-link support for `?focus=escalations`.
- Added field-escalation and resolved icons to the existing bell.
- All newly introduced interactive controls have a minimum 44px touch height.
- Existing large pages contain wiring only:
  ApartmentDashboardPage.js: 5 added / 1 removed line.
  ProjectDashboardPage.js: 17 added / 5 removed lines.
